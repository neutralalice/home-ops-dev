# Disaster recovery for dummies

## Snapshots

The core of everything is the automatic snapshots that take place according to
the policies and schedules.

### Manual snapshots

manual snapshots target a policy, and trigger a one off. The resources might
look like this, but using existing policies is preferred

```yaml
---
apiVersion: kopiur.home-operations.com/v1alpha1
kind: Snapshot
metadata:
    name: hister-demo-manual
    namespace: default
spec:
    policyRef:
        name: hister-demo-manual
    deletionPolicy: Retain
    pin: true
    failurePolicy:
        backoffLimit: 2
        activeDeadlineSeconds: 7200
        podStartupDeadlineSeconds: 300
```

```yaml
---
apiVersion: kopiur.home-operations.com/v1alpha1
kind: SnapshotPolicy
metadata:
    name: hister-demo-manual
    namespace: default
spec:
    compression:
        compressor: zstd
    mover:
        resources:
            limits:
                cpu: 1000m
                memory: 1024Mi
            requests:
                cpu: 20m
                memory: 1024Mi
        securityContext:
            runAsUser: 65532
            runAsGroup: 65532
    repository:
        kind: ClusterRepository
        name: aureole
    sources:
        - pvc:
              name: hister
    copyMethod: Snapshot
    hooks:
        beforeSnapshot:
            - workloadExec:
                  podSelector:
                      matchLabels:
                          app.kubernetes.io/name: hister
                  container: app
                  command: ["/bin/sh", "-c", "touch /hister/data/BEFORESNAPHOOK.txt"]
                  timeout: 2m

    retention:
        keepDaily: 14
        keepWeekly: 6
        keepMonthly: 3
    volumeSnapshotClassName: ceph-block-snap
```

## Restore

Take an existing snapshot, and restore it to a new pvc

```yaml
---
apiVersion: kopiur.home-operations.com/v1alpha1
kind: Restore
metadata:
    name: restore-verify-hister
    namespace: default
spec:
    source:
        fromPolicy:
            name: hister-demo-manual
            offset: 0 # 0 = latest, 1 = previous, ...
    target:
        pvc:
            name: hister-data-restored
            capacity: 10Gi
        accessModes:
            - ReadWriteOnce
```
